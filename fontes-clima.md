# Fontes de clima (lista do Nei, 09/10/2026)

Regra: separar **observado** (estações, satélite), **previsão de modelo** e **análise jornalística**. APIs de clima gratuitas liberadas pelo Nei em 09/10/2026.

| Fonte | Para quê | Acesso |
|---|---|---|
| MetSul — https://metsul.com/ | notícias e interpretação, eventos extremos no Sul | páginas |
| Meteologix — https://meteologix.com/br/model-charts/euro/rio-grande-do-sul/accumulated-precipitation.html | chuva acumulada, rajadas, comparação ECMWF/GFS/ICON/AIFS, ensembles | páginas (mapas) |
| INMET — https://portal.inmet.gov.br/ · avisos https://avisos.inmet.gov.br/ · BDMEP https://bdmep.inmet.gov.br/ | alertas oficiais (lista de municípios), estações | JSON público `apiprevmet3.inmet.gov.br/avisos/ativos`, CSV |
| CPTEC/INPE — https://www.cptec.inpe.br/ · SIGMA https://sigma2.cptec.inpe.br/ | satélite, raios, modelos brasileiros | imagens |
| CEMADEN — https://mapainterativo.cemaden.gov.br/ | pluviômetros por município, chuva intensa | séries |
| NASA GIBS (GOES-19/NOAA) — https://gibs.earthdata.nasa.gov/ | satélite GeoColor e infravermelho (topo das nuvens) | WMS livre |
| Open-Meteo — https://open-meteo.com/ | previsão por ponto/grade (ECMWF, GFS, ICON), histórico | API livre, JSON/CSV |
| Windy — https://www.windy.com/ | animações de vento/chuva | visual (Premium pago: não) |
| Meteoblue — https://www.meteoblue.com/ | meteogramas, histórico | visual; CSV comercial (não) |
| Tropical Tidbits — https://www.tropicaltidbits.com/ | mapas de modelos, ciclones | visual, restrição de uso |
| NOAA — https://www.noaa.gov/ · NCEI https://www.ncei.noaa.gov/cdo-web/ | climatologia | dados |
| ECMWF — https://www.ecmwf.int/ | modelos globais | conforme produto |
| Zoom Earth — https://zoom.earth/ | satélite e tempestades | visual |
